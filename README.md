## 💡 Sobre o Projeto
A **Plataforma Mão Amiga** resolve o problema clássico da contratação de prestadores de serviço: a falta de previsibilidade, segurança e histórico de avaliações. O produto entrega um aplicativo móvel rápido e um painel web que viabilizam solicitação de orçamentos, validação de profissionais e chat de negociação.

---

## 🛠️ Stack Tecnológica
- **Backend:** **PHP/Laravel** com **Express** e **TypeScript** tipado de ponta a ponta
- **Mobile:** **React Native** (Expo), interfaces desenhadas para uso prático com uma mão
- **Estilização:** **TailwindCSS** com design system consistente entre Web e App
- **Banco de Dados:** **MySQL** relacional com modelagem normalizada (E-R)
- **Autenticação:** Tokens JWT com refresh tokens seguros e criptografia de senhas (bcrypt)

---

## ⚡ Recursos Destacados
- **Perfil Verificado de Prestadores:** Espaço para portfólio de serviços executados, especialidades e avaliações com comentários de clientes reais.
- **Orçamentos Estruturados:** Fluxo de solicitação onde o cliente detalha a demanda e recebe cotações de forma padronizada.
- **Compilação Mobile Real:** App testado e validado em aparelhos Android com build de APK funcional.
